Instruções para a prática

Membro 1 da dupla

1. Executar o "fork" do repositório
2. Clonar o repositório na sua máquina localmente (git clone <link>)
3. Adicione a sua dupla como colaborador no repositório
4. Criar uma branch com o nome feat/nome-fib ou feat/nome-fat (dependendo de qual função for implementar)
5. Criar um arquivo, no diretório "duplas/", por dupla com o formato de nome Nome1-Nome2.c e copiar a estrutura do exemplo "modelo.c"
6. Mudar para a sua branch (criada no passo 3)
7. Implementar a função, uma por membro da dupla, e dar o push da modificações
8. Gerar o pull request com o merge da branch atual para a main (para o repositório forkeado)
9. Gerar o pull request com o merge da branch main para a main do repositório principal

4. Mudar para a sua branch (criada no passo 3)
5. Implementar a função, uma por membro da dupla, e dar o push da modificações
6. Gerar o pull request com o merge da branch atual para a main (para o repositório forkeado)
